# Yakın Boğaz

Yakın Boğaz yazılım stüdyosu için animasyonlu, statik Next.js websitesi.

## Geliştirme

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) adresinde açılır.

## Statik üretim

```bash
npm run build
```

Çıktı `out/` klasörüne yazılır; herhangi bir statik hosting’e yüklenebilir.
